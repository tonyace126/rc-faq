QA 編輯工具 給 TONY 用 · 不會公開到網站
使用流程： 點「載入 faqs.json」拉現有資料 → 編輯或新增 → 點「下載 faqs.json」覆蓋原檔 → 把圖片放進 images/ 並 push 到 GitHub。
圖片做法：先把截圖檔名命名為 INV-001-a.png 這種規則，存進 repo 的 images/，再在「相關截圖」欄填路徑：images/INV-001-a.png。

還沒選擇 QA

從左邊清單選一筆來編輯，或點右上「＋ 新增 QA」。

完整 faqs.json

把這份內容存成 data/faqs.json（或直接點下方下載）取代你 GitHub repo 裡的舊檔。
