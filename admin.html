⚙️ GitHub 連線設定

設定一次後，admin.html 改完按「推送」就會直接更新到 GitHub Pages，不用再手動複製貼上。 Token 只會儲存在這個瀏覽器（localStorage），不會上傳到任何地方。

不知道怎麼產生 Token？
  1. 到 GitHub Token 設定頁（Fine-grained tokens）
  2. Token name 隨意（例：rc-faq-admin）；Expiration 建議 90 days 或 No expiration
  3. Repository access 選「Only select repositories」→ 選 rc-faq
  4. Repository permissions 找到「Contents」→ 改成 Read and write
  5. 下方 Generate token → 複製產生的字串（github_pat_...）→ 貼到上面 Token 欄
⚠️ Token 只會顯示一次，請妥善保管。如不小心外流，回該頁面 Revoke 即可。
